Ultimate Studio Suite Pro

Ultimate Studio Suite คือโปรแกรม Desktop Application แบบ 3-in-1 ที่ออกแบบมาเพื่อคนทำสถานีวิทยุ ดีเจ และนักสร้างสรรค์คอนเทนต์เสียงโดยเฉพาะ รวบรวมเครื่องมือที่จำเป็นทั้งหมดไว้ในหน้าต่างเดียว ใช้งานง่ายด้วย GUI ที่ทันสมัยสไตล์ Pro Tools และมีระบบจัดการหลังบ้านที่เสถียร

พัฒนาโดย: คุณสุรเดช เจียรนัย (Suradech)

✨ ฟีเจอร์หลัก (Features)

โปรแกรมแบ่งการทำงานออกเป็น 3 ระบบหลัก (แท็บ):

1. 📻 Auto-Mix Engine (ระบบจัดรายการวิทยุอัตโนมัติ)

Smart Silence Detection: ตรวจจับช่องว่างความเงียบของไฟล์เสียงดีเจ (Main Show) ที่ระดับ -60dB อย่างแม่นยำ

Auto-Insertion: แทรกไฟล์สปอตโฆษณา (Ads) และรีวิวสินค้า (Tie-in) ลงในช่องว่างอัตโนมัติตามโควต้าที่ตั้งไว้

Audio Mastering: ปรับระดับเสียง (Loudnorm) ให้ไฟล์ที่มิกซ์เสร็จแล้วมีความดังมาตรฐานสากล (-14 LUFS)

2. ✂️ Audio Splitter (ระบบหั่นเสียงนิทาน/อาจารย์ยอด)

True Natural Cut: วิเคราะห์ค่าพลังงานเสียง (RMS) แบบ Pure Python เพื่อหาจุดตัดที่เสียงเงียบที่สุด ป้องกันการตัดฉับกลางคำพูด

Auto-Fade & Normalize: ปรับระดับเสียงให้ดังชัดเจน พร้อมทำ Fade-in/Fade-out หัวท้ายให้อัตโนมัติ

Batch Processing: รองรับการหั่นไฟล์ MP4/MP3 ทีละหลายๆ ไฟล์ในโฟลเดอร์เดียว

3. 📥 YouTube Downloader (ระบบดาวน์โหลดคลิป/เพลง)

High-Quality Download: รองรับการดาวน์โหลดวิดีโอระดับ 1080p, 4K และแปลงเป็นไฟล์เสียง MP3 (320kbps)

Playlist Support: รองรับการดาวน์โหลดทั้ง Playlist พร้อมสร้างโฟลเดอร์แยกให้อัตโนมัติ

Live Preview: แสดงภาพหน้าปก (Thumbnail) ชื่อคลิป ชื่อช่อง และความยาวคลิปก่อนดาวน์โหลด

🚀 วิธีการติดตั้งและใช้งาน (Installation)

เนื่องจากโปรแกรมถูกแพ็กเป็นไฟล์ .exe แบบ Standalone คุณจึงไม่ต้องติดตั้งโปรแกรมใดๆ เพิ่มเติม

ไปที่เมนู Releases ทางขวามือของหน้า GitHub นี้

ดาวน์โหลดไฟล์ UltimateStudio_v3.exe เวอร์ชันล่าสุด

นำไฟล์ .exe ไปวางไว้ในโฟลเดอร์ที่คุณต้องการทำงาน

เมื่อเปิดโปรแกรมครั้งแรก (ในหมวดวิทยุ) โปรแกรมจะสร้างโฟลเดอร์สำหรับทำงานให้ 5 โฟลเดอร์:

main_shows/ - สำหรับใส่ไฟล์เสียงจัดรายการหลัก

ads/ - สำหรับใส่ไฟล์สปอตโฆษณา

product_reviews/ - สำหรับใส่ไฟล์รีวิวสินค้า

ajarn_yod/ - สำหรับใส่ไฟล์เสียงนิทาน

output/ - โฟลเดอร์รับไฟล์ที่มิกซ์เสร็จเรียบร้อย

🔄 ระบบอัปเดตอัตโนมัติ (Auto-Updater)

โปรแกรมมีระบบเช็คอัปเดตเวอร์ชันใหม่ในตัว เมื่อผู้พัฒนาปล่อยเวอร์ชันใหม่บน GitHub ผู้ใช้งานสามารถกดปุ่ม "เช็คอัปเดตเวอร์ชันใหม่" ในหน้า "ตั้งค่าระบบ" โปรแกรมจะทำการดาวน์โหลดและติดตั้งตัวมันเองใหม่ให้โดยอัตโนมัติ

(อ้างอิงเวอร์ชันล่าสุดจากไฟล์ version.json ใน Repository นี้)

🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

GUI Framework: CustomTkinter (Dark Theme)

Audio Processing: FFmpeg, Pydub (Pure Python RMS logic)

Downloader Engine: yt-dlp

Compiler: PyInstaller
